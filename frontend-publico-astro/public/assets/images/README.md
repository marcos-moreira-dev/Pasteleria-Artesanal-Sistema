# Assets De Imagen

- `branding/`: logos y marca.
- `icons/`: favicon e iconos de navegación si hacen falta.
- `placeholders/`: imágenes temporales para hero, catálogo o bloques promocionales.
- `fonts/`: tipografías locales cuando se definan.

Regla:
- no depender de CDNs para marca o fuentes finales;
- usar placeholders locales mientras no existan assets definitivos.

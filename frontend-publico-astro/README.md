# Frontend Público Astro

Superficie pública comercial para mostrar catálogo, transmitir marca y recibir solicitudes de cotización.

## Qué ya cubre

- landing en `es/en`
- catálogo público en `es/en`
- contacto comercial en `es/en`
- formulario público de solicitud de cotización
- consumo tolerante del backend para catálogo

## Comando principal

`npm run dev`

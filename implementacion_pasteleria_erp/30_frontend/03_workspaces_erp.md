# Workspaces ERP Angular

T23 agrega una pantalla administrativa `/erp` que agrupa vistas por dominio sin romper la UX/UI original de Pastelería.

## Dominios visibles

- Inteligencia.
- Terceros.
- Cartera.
- Cuentas por pagar.
- Contabilidad.
- Fiscalidad.
- Bridges ERP.

## Regla UX/UI

La pantalla usa la carcasa existente, tablas existentes, tarjetas existentes, botones existentes y estilos de `ADMIN_SURFACE_STYLES`.

No se copió la estética de Cedro ni se introdujo una pantalla externa al lenguaje visual de Pastelería.

## Estado funcional

La pantalla es principalmente de consulta. Las acciones mutantes se mantienen prudentes para tandas posteriores, cuando se agreguen confirmaciones, permisos visibles y validaciones de usuario final.

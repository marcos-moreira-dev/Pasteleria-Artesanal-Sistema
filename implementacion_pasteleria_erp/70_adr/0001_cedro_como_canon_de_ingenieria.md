# ADR 0001 — Cedro como canon de ingeniería

## Estado

Aceptado.

## Contexto

Cedro es un proyecto más maduro en arquitectura, operación, scripts, migraciones, guía operativa, backend transversal, identity, reportes, storage, auditoría, soporte, tests y evidencia.

## Decisión

Usar Cedro como canon de ingeniería para evolucionar la pastelería hacia ERP.

## Consecuencias

Se rescata:

- gobierno documental;
- scripts simples;
- guía operativa;
- contratos API;
- ApiResponse;
- requestId;
- storage seguro;
- identity multi-sucursal;
- ERP Bridge conceptual;
- tests y evidencia.

No se rescata:

- estética Cedro;
- dominio restaurante literal;
- assets Cedro;
- nombres Cedro;
- puertos Cedro;
- clases gigantes sin refactor;
- fiscalidad avanzada como promesa final.

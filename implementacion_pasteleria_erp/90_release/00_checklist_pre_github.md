# Checklist pre-GitHub

## Estado

Borrador vigente inicial.

Antes de subir o presentar el proyecto como versión seria:

- Backend compila.
- Admin Angular compila.
- Storefront compila.
- V1/V2 cargan en PostgreSQL limpio.
- Tests base pasan.
- Smoke API pasa.
- Guía Operativa abre.
- Guía Operativa PDF descarga.
- Reportes PDF descargan.
- No hay stock negativo.
- No hay asientos descuadrados registrados.
- No hay caja con doble turno abierto.
- No se rompió UX/UI actual.
- No se rompió storefront.
- Fiscalidad está marcada como preparada, no certificada.
- Existe evidencia de validación.

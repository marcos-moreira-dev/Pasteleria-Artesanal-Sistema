# Definition of Done

## Estado

Vigente.

Una tanda no está terminada solo porque compila o se ve bonita.

## Toda tanda debe revisar

- documentación;
- backend;
- frontend;
- base de datos;
- contratos API;
- seguridad;
- tests;
- UX/UI actual;
- storefront;
- riesgos.

## Módulos críticos

Para módulos críticos debe existir prueba, smoke test o validación explícita:

- caja;
- inventario;
- producción;
- compras;
- cartera;
- tesorería;
- contabilidad;
- fiscalidad;
- reportes;
- permisos;
- guía operativa.

## Criterio

Si se toca comportamiento crítico sin prueba ni validación, la tanda queda incompleta.

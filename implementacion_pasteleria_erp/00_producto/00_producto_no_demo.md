# Producto serio, no arquitectura demo

## Estado

Vigente.

## Regla

La pastelería debe tratarse como producto serio desde el inicio. La palabra “demo” solo puede usarse para datos de presentación, perfil `presentation`, capturas, ejemplos o evidencia temporal.

## Permitido

Se permite usar “demo” en:

- seeds de presentación;
- perfil `presentation`;
- datos de muestra;
- capturas para mostrar el sistema;
- evidencia temporal;
- storage de presentación.

## No permitido

No usar “demo” para nombrar o justificar:

- arquitectura;
- backend;
- frontend;
- base de datos productiva;
- seguridad;
- contratos API;
- caja;
- inventario;
- producción;
- contabilidad;
- fiscalidad;
- reportes;
- guía operativa.

## Criterio

El sistema puede tener datos de presentación, pero no debe construirse como una aplicación descartable.

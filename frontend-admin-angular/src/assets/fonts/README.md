# Fonts

Fuentes locales activas del panel administrativo:

- `CormorantGaramond-Variable.ttf`
  Origen: Google Fonts / Google Fonts GitHub
  Uso: encabezados, jerarquia de panel y metricas destacadas
  Licencia: SIL Open Font License 1.1
- `SourceSans3-Variable.ttf`
  Origen: Google Fonts / Google Fonts GitHub
  Uso: tablas, formularios, navegacion y texto operativo
  Licencia: SIL Open Font License 1.1

Regla:
- el panel debe funcionar sin depender de servicios externos de fuentes;
- si el negocio entrega una tipografia final, documentar origen/licencia antes de reemplazar estos archivos.

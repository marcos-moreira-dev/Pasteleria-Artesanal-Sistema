# Assets De Imagen

- `branding/`: logos y elementos de marca.
- `icons/`: favicon y pequeños iconos internos.
- `placeholders/`: paneles o vistas temporales para material de presentación.
- `fonts/`: tipografías locales.

Regla:
- toda marca e iconografía importante debe vivir en el repo;
- mientras no exista la versión final, usar placeholder local.

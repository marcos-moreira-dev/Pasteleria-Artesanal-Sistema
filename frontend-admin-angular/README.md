# Frontend Admin Angular

Consola administrativa y operativa para atención, cotizaciones, pedidos y producción.

## Qué ya cubre

- login conectado al backend
- shell de navegación por módulos
- tablero operativo
- lectura de clientes, productos, cotizaciones, pedidos y producción
- formularios base para registrar clientes, cotizaciones y pedidos
- acciones básicas de estado para pedido y producción

## Comando principal

`npm start`

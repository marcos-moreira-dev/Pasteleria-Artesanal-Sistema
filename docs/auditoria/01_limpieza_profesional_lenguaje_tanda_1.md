# Tanda 1 — Limpieza profesional de lenguaje

## Resultado

Se retiró lenguaje provisional como concepto visible y se normalizaron textos para que Pastelería se lea como producto profesional.

## Cambios realizados

- Renombradas migraciones de datos de arranque y datos operativos.
- Renombrado el runbook de presentación local.
- Reemplazadas credenciales visibles por **Accesos locales de revisión**.
- Corregidos textos con mojibake detectado.
- Reemplazados ejemplos como proveedor y cliente de revisión.

## Criterio aplicado

El proyecto puede tener datos iniciales para revisar el sistema, pero no debe presentarse como maqueta ni como entrega provisional.

# 01 — Levantamiento de información del negocio

## 1. Propósito del documento

Este documento describe cómo funciona la operación diaria de la pastelería desde el punto de vista del negocio. El objetivo es identificar los procesos, actores y flujos de información que existen actualmente.

Este documento **no define aún requerimientos de software**, sino que describe cómo opera el negocio en la práctica.

---

## 2. Actores principales del negocio

### 2.1 Cliente

Persona que compra productos de la pastelería o solicita un pedido especial.

Puede interactuar con el negocio de varias formas:

- visitando el local
- realizando una consulta por teléfono
- enviando un mensaje
- realizando un pedido anticipado

### 2.2 Personal de atención

Encargado de atender a los clientes, registrar pedidos y entregar productos.

Responsabilidades principales:

- atender consultas
- registrar pedidos
- coordinar fechas de entrega
- cobrar productos o anticipos

### 2.3 Personal de producción

Encargado de preparar los productos en la cocina o área de producción.

Responsabilidades principales:

- preparar productos de vitrina
- elaborar tortas por encargo
- cumplir con fechas de producción

### 2.4 Administrador o propietario

Responsable de supervisar el negocio y tomar decisiones operativas.

Responsabilidades principales:

- definir precios
- revisar ventas
- supervisar pedidos
- organizar producción

---

## 3. Tipos de interacción con clientes

### 3.1 Compra directa en el local

El cliente llega al local y compra un producto disponible en vitrina.

Flujo típico:

1. cliente observa productos disponibles
2. selecciona producto
3. personal registra venta
4. cliente realiza pago
5. producto es entregado

### 3.2 Pedido de torta completa

El cliente solicita una torta completa estándar.

Flujo típico:

1. cliente consulta disponibilidad
2. personal confirma opciones disponibles
3. se registra el pedido
4. se acuerda fecha de entrega
5. se puede registrar anticipo

### 3.3 Pedido de torta personalizada

El cliente solicita una torta con características específicas.

Información que normalmente se solicita:

- tamaño de la torta
- sabor
- relleno
- tipo de decoración
- mensaje personalizado
- fecha de entrega

El personal registra la solicitud y coordina con producción.

---

## 4. Registro de pedidos

Cuando se recibe un pedido anticipado, normalmente se registra información como:

- nombre del cliente
- teléfono de contacto
- descripción del producto solicitado
- fecha de entrega
- observaciones
- monto del anticipo

Esta información puede registrarse actualmente en:

- cuadernos
- hojas de cálculo
- mensajes

---

## 5. Planificación de producción

La cocina debe preparar productos según:

- pedidos programados
- reposición de productos de vitrina

El personal revisa los pedidos del día o de días siguientes para organizar el trabajo.

---

## 6. Entrega de pedidos

Cuando llega la fecha de entrega:

1. cliente llega al local
2. personal verifica el pedido
3. cliente cancela saldo pendiente
4. pedido es entregado

---

## 7. Información importante para el negocio

Durante la operación diaria se manejan diferentes tipos de información:

- datos de clientes
- productos disponibles
- pedidos registrados
- fechas de entrega
- pagos y anticipos

Esta información es importante para evitar errores y cumplir con los pedidos correctamente.

---

## 8. Problemas comunes en la operación manual

Cuando el negocio se gestiona con métodos manuales pueden ocurrir problemas como:

- pérdida de información de pedidos
- confusión en fechas de entrega
- dificultad para revisar pedidos pendientes
- errores en comunicación entre atención y cocina

---

## 9. Observaciones del levantamiento

El análisis del funcionamiento del negocio permite identificar que existen procesos repetitivos que podrían organizarse mejor con un sistema de información.

Estos procesos incluyen principalmente:

- registro de pedidos
- seguimiento de producción
- consulta de pedidos pendientes

---

## 10. Conclusión

El levantamiento de información del negocio permite comprender cómo opera actualmente la pastelería y cuáles son los flujos de trabajo principales.

Esta información servirá como base para el siguiente documento, donde se definirán los requerimientos del sistema de software.

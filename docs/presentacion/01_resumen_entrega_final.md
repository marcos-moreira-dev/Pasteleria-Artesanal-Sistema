# Resumen de Entrega

Resumen ejecutivo del estado del proyecto.

## Entregado

- Backend Spring Boot modular con seguridad JWT, auditoría, notificaciones,
  reportes async, catálogo, clientes, cotizaciones, pedidos, producción y
  abastecimiento.
- Frontend administrativo Angular.
- Frontend público Astro.
- Arquitectura de assets centralizada en backend.

## Validación mínima

- Backend: `mvnw.cmd test`
- Admin Angular: `npm run build`
- Landing Astro: `npm run build`

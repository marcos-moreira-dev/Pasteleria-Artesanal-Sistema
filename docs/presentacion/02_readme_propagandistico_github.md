# README Propagandistico para GitHub

Guia auxiliar para preparar la version publica del repositorio.

La fuente de verdad del README publico ya es `README.md`.

Este documento no debe repetir su contenido; solo debe ayudar a cerrarlo mejor.

---

## Para que sirve este documento

Sirve para:

- planificar capturas
- mantener una narrativa comercial coherente
- decidir que ventanas merecen mostrarse en GitHub
- evitar que el README termine duplicando documentacion tecnica canonica

---

## Estructura recomendada del README publico

1. Hero o collage principal.
2. Resumen de valor del sistema.
3. Stack de alto nivel.
4. Arranque minimo.
5. Recorrido visual del frontend publico.
6. Recorrido visual del frontend administrativo.
7. Enlace a documentacion canonica.

---

## Regla de no redundancia

El README publico:

- resume
- vende
- orienta

La documentacion canonica:

- explica
- profundiza
- congela decisiones

No conviene duplicar en ambos la misma guia operativa larga.

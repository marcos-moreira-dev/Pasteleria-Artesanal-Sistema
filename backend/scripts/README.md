# Scripts backend

Estos scripts quedan como compatibilidad para tareas puntuales del backend.

Para uso diario, preferir los puntos de entrada de la raíz:

```bat
scripts\test-backend.bat
scripts\run-production.bat
scripts\run-demo.bat
```

Los scripts de esta carpeta pueden delegar en esos puntos de entrada o en la lógica auxiliar de `tools\powershell`.
